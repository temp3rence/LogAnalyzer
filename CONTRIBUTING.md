# Contributing to LogAnalyzer

## Workflow

1. Create a new branch from main.
2. Make changes in the new branch.
3. Check the changes locally.
4. Commit the changes.
5. Push the branch to GitHub.
6. Open a Pull Request.
7. Review and merge the changes.

## Commit messages

Use clear and descriptive commit messages.

Examples:
- docs: update README
- fix: correct log parsing
- feat: add log filtering
